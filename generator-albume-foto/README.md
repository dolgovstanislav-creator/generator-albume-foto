# Generator simplu de albume foto

## Cum deschizi proiectul în Visual Studio Code

1. Descarcă și dezarhivează folderul `generator-albume-foto`.
2. Deschide Visual Studio Code.
3. Alege **File → Open Folder** și selectează folderul proiectului.
4. Deschide fișierul `index.html`.
5. Pentru a vedea site-ul, deschide `index.html` în browser. Recomandat: extensia **Live Server** din VS Code, apoi click dreapta pe `index.html` → **Open with Live Server**.

## Ce poate face site-ul

- Schimbi numele albumului.
- Încarci mai multe fotografii de pe calculator.
- Vezi fotografiile într-o galerie.
- Ștergi o fotografie individuală sau toate fotografiile.

Fotografiile sunt afișate local în browser; site-ul nu le încarcă pe un server.
